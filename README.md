バトル・サモンズは、カードを使用して様々な武器を召喚し、敵を撃破する3Dアクションゲームです。



プレイヤーはカードのレアリティ（Bronze / Silver / Gold）を切り替えながら、射撃や砲撃などの攻撃を使い分けて戦います。レアリティによって攻撃力や性能が変化し、状況に応じた戦い方を楽しめるよう設計しました。

ゲームシステム

射撃

前方へ弾を発射します。

レアリティに応じて攻撃力や弾の性能が変化します。

砲撃

プレイヤーの前方へ砲台を設置します。

砲台から砲弾を発射し、着弾時に爆風ダメージを与えます。

爆風は範囲攻撃となっており、距離判定によってダメージを与えています。

カードシステム

Bronze / Silver / Gold の3段階のレアリティを実装しました。

レアリティごとに攻撃力やサイズなどのパラメータを変更しています。

工夫した点

オブジェクト指向を意識した設計



カードの共通処理を基底クラスにまとめ、射撃・砲撃などの個別処理は派生クラスへ実装することで、新しいカードを追加しやすい構成にしました。



当たり判定



弾と敵の当たり判定には球体判定とカプセル判定を組み合わせ、高速で自然な衝突判定を実現しました。また、高速で移動する弾のすり抜けを防ぐための判定処理も実装しています。



エフェクト



Effekseerを利用し、砲弾の爆発エフェクトを実装しました。エフェクトの再生タイミングとダメージ判定を同期させることで、見た目とゲームプレイの違和感を減らしました。



サウンド管理



SoundManagerを作成し、BGMと効果音を一元管理しました。ゲーム内のイベントに応じて適切な効果音やBGMを再生できるよう設計しています。



コード設計



クラスごとに責務を分離し、可読性・保守性・拡張性を意識して実装しました。共通処理を整理することで、機能追加や修正を行いやすい構成を目指しました。
